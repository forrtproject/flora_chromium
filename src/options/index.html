Extension Setup

FORRT ORE — Open Research Extension

Configure ORE to start surfacing replication evidence, retractions, comments and open access on the papers you read.
Why we ask for your email

ORE queries the Crossref and OpenAlex APIs to resolve article DOIs. Both services ask for a contact email so they can place your requests in their polite-access pool — meaning faster rate limits and more reliable lookups while you browse.

Your email is used only as a mailto parameter sent to Crossref & OpenAlex and Unpaywall. It is never stored on a FORRT server, shared, or used for anything else.

Copy Citation

Citation Style

Every DOI pill has a Citation row that copies the reference in one click. Pick the style it uses here — that style, and only that style, is what the pill copies. The copy keeps its formatting, so italics survive a paste into Word or Google Docs; anywhere that takes plain text gets plain text. Citations are rendered by Crossref and fetched only when you ask for one.

Performance

Cache Storage Limit

ORE stores lookup results locally so pages load faster on repeat visits. This shared limit covers all data providers; your settings and diagnostic logs are kept separately. Enter 0 for unlimited.

Blocked Domains

Site Blocklist

ORE runs on all websites by default. Add domains here to prevent it from scanning them.

PubPeer Comments

Muted Commenters

ORE shows PubPeer threads in its Meta Report panel. Add a commenter's display name — the name shown on their comment, such as Statcheck or a pseudonym like Anolis Jacare — to hide their comments from that panel. FORRT is muted by default because the panel already shows its data; remove it below if you'd rather see those comments too.

Troubleshooting

Debug Mode & Issue Reports

If something looks wrong, switch debug mode on, reload the page that misbehaves and reproduce the problem — ORE then keeps a log of what it did. Report the issue and that log is written straight into the GitHub form; read it here first if you'd like to see what you're sending.
What the log contains

The log records what ORE looked up and where: DOIs found on the pages you visit, the hostnames of those pages, API outcomes and any errors. It stays on this computer and is never sent anywhere until you choose to open an issue with it — and nothing is submitted until you press GitHub's own button.

Your email address is never included. Read the report below before you share it — a GitHub issue is public.
